# TDDE83 – labbrepo

Detta är ditt labbrepo för [TDDE83](https://python-d-u.gitlab-pages.liu.se/course-docs/).

Varje labb har en egen färdig mapp där du lägger dess filer.  Ofta finns det redan
förberedda filer i mappen.

Labbtexten säger vilken mapp du ska vara i när du kör kommandon.  Det kan vara en annan 
mapp än labbens egen mapp.

- `lab-b1/`
- `lab-b2/`
- `lab-b3/`
- `lab-b4/`
- `lab-b5/`
- `lab-b6/`

Filen `.python-version` med texten `3.14` ligger både i repots rotmapp och i
labbarnas respektive mappar.
Den bestämmer vilken Python-version `uv run` startar, så låt den ligga kvar.
